# ✦ Creative Hub — библиотека творчества Ame Tanami

Маленький сайт-каталог: игры, галерея, ссылки. Работает на GitHub Pages без сервера.

**Весь контент лежит в папке `content/` и `assets/`. Код (`index.html`, `css/`, `js/`) для добавления контента трогать не нужно.**

```text
index.html          — каркас страницы
css/style.css       — оформление (цвета и шрифты — в самом начале файла)
js/app.js           — логика
content/
  site.json         — имя, приветствие, тексты разделов, соцсети
  games.json        — игры и интерактивы
  gallery.json      — подборки галереи и комиксы
  links.json        — ссылки и всякое
assets/
  common/           — аватарка и общие картинки
  games/            — превью игр
  links/            — превью ссылок
  gallery/<id>/     — по папке на каждую подборку
```

---

## ✦ Самый простой способ: папка `_originals` + кнопка

1. Положить картинки (PNG/JPG, любого размера и с любыми именами) в `_originals/`:

   ```text
   _originals/
     gallery/
       Ведьмочки/              ← имя папки = название подборки
         Witchtober_01.png
         Witchtober_02.png
         обложка.png           ← файл со словом «обложка» или «cover» станет обложкой
       Я и моя боязнь высоты/
         Боязнь высоты.png
         Боязнь высоты1.png
     games/
       Cats flood/             ← папка = название карточки из games.json
         cover.png             ← обложка карточки
     links/
       Спидпейнты/
         cover.png
     common/                   ← avatar.png и прочее
   ```

2. Запустить обновление одним из способов:
   - в **VS Code**: `Ctrl+Shift+B`;
   - в **Проводнике Windows**: двойной клик по `обновить-картинки.bat` (в VS Code двойной клик просто открывает файл как текст);
   - в терминале: `node tools/build-images.mjs`.

   В первый раз нужен интернет — скачается конвертер (`.bat` делает это сам, в терминале — `npm install`).

Скрипт уменьшит картинки до 1600px, сохранит в WebP, сделает маленькие превью для сетки,
переведёт имена в латиницу и сам обновит `content/gallery.json`. Подписи, вписанные вручную, сохранятся.

- **Порядок** — по имени файла, числа учитываются: `высоты`, `высоты1`, `высоты2`, `высоты10`.
- **Новая папка** в `_originals/gallery/` → новая подборка на сайте. Потом в `gallery.json` можно
  дописать ей `description`, `group` и, для комикса, `"layout": "strip"`.
- **Удалили оригинал** → картинка пропадёт и с сайта.
- **Пустая папка** → подборку скрипт не трогает.
- Посторонние файлы (`.clip`, `.mp4`, `.psd`…) пропускаются — можно копировать рабочую папку целиком.
- Уже сконвертированные картинки повторно не обрабатываются. Пересобрать всё: `node tools/build-images.mjs --force`.
- **Игры и ссылки:** у каждой карточки своя папка с тем же названием, что в JSON. Обложка — файл со словом «cover»/«обложка» (или единственная картинка в папке). Путь в поле `image` скрипт впишет сам. Двоеточия и другие запрещённые в именах папок символы можно просто пропустить: «Анимированные 50 оттенков спасибо» найдёт «Анимированные: 50 оттенков спасибо».
- **Новая игра:** сначала добавить карточку в `content/games.json` (название и ссылку), потом папку с обложкой.

Папка `_originals/` на GitHub не загружается (она в `.gitignore`) — туда уходят только лёгкие WebP.
Настройки размера и качества — в начале `tools/build-images.mjs`.

## Как добавить игру

Открыть `content/games.json` и добавить блок в список:

```json
{
  "title": "Название игры",
  "description": "Пара слов о том, что это.",
  "image": "assets/games/my-game.webp",
  "url": "https://...",
  "tag": "Браузерная игра",
  "status": "new",
  "featured": true
}
```

Обязательны только `title` и `url`. Остальное по желанию:

| Поле | Что делает |
|---|---|
| `description` | короткое описание под названием |
| `image` | превью; если файла нет — будет цветная заглушка ✦ |
| `tag` | маленькая подпись над названием («Telegram-бот», «Марафон») |
| `status` | `new` → «Новое», `active` → «Идёт», `archived` → «Архив» (карточка становится бледнее) |
| `featured` | `true` — показать карточку на главной в блоке «Сейчас интересно» |
| `hidden` | `true` — временно спрятать, не удаляя |

Порядок карточек на сайте = порядок в файле.

Клик по игре открывает её страницу: обложка, тег и статус, описание и кнопка. Дополнительные поля:

| Поле | Что делает |
|---|---|
| `about` | длинное описание для страницы игры (в карточке остаётся короткое `description`). Переносы строк — `
` |
| `linkLabel` | текст кнопки, по умолчанию «Играть ✦» (у ботов — «Открыть бота ✦») |
| `id` | адрес страницы (`#games/cats-flood`); если не указан — берётся из названия |

## Как добавить ссылку

`content/links.json` — те же поля, что у игр. Подходит для стикерпаков, видео, постов, обзоров.

## Галерея

### Добавить картинки в существующую подборку

1. Положить файлы в папку подборки, например `assets/gallery/watercolor/`.
2. Вписать их имена в `images` этой подборки в `content/gallery.json`.

```json
"images": [
  "01.webp",
  "02.webp",
  { "src": "03.webp", "caption": "Сатаплия — древний лес с динозаврами" }
]
```

Просто имя файла — картинка без подписи. Объект с `caption` — картинка с подписью
(подпись видна под картинкой и в увеличенном просмотре). Порядок в списке = порядок на сайте.

### Новая подборка

1. Создать папку `assets/gallery/<id>/`, где `<id>` — короткое имя латиницей без пробелов (`sketchbook-2025`).
2. Положить туда картинки и обложку `cover.webp`.
3. Добавить блок в `content/gallery.json`:

```json
{
  "id": "sketchbook-2025",
  "title": "Скетчбук 2025",
  "description": "Необязательное описание.",
  "group": "Арты",
  "cover": "cover.webp",
  "images": ["01.webp", "02.webp"]
}
```

| Поле | Что делает |
|---|---|
| `id` | **обязательно**; имя папки и адрес страницы (`#gallery/sketchbook-2025`) |
| `title` | название |
| `shelfTitle` | другое название на корешке книги на полке (например, зацензуренное), внутри подборки остаётся `title` |
| `description` | описание под заголовком |
| `group` | полка, на которой стоит подборка («Арты», «Комиксы»). Каждая группа — отдельная полка и на главной, и в галерее; порядок полок = порядок первого появления в `gallery.json` |
| `cover` | обложка; если не указана — берётся первая картинка |
| `layout` | `"book"` — книга с перелистыванием, `"strip"` — горизонтальная лента. Без поля — сетка |
| `color` | цвет корешка на полке, например `"#5a3b6e"`. Без поля — подбирается сам |
| `folder` | другая папка, если картинки лежат не в `assets/gallery/<id>/` |
| `featured`, `hidden` | как у игр |

### Подподборки (папки в папке)

Если внутри папки подборки есть папки с картинками — это подподборки:

```text
_originals/gallery/Ведьмочки/
  Witchtober 2024-2025/
  Witchtober 2026/
```

На полке стоит одна книга «Ведьмочки», внутри — карточки подподборок, у каждой своя сетка (или книга).
Скрипт сам добавит их в `gallery.json` с полем `"parent"`. Порядок карточек = порядок в `gallery.json`, его можно менять вручную.
Если у подборки есть и свои картинки, и подпапки — сначала покажутся картинки, ниже «Ещё в этой подборке».

### Полка или карточки

В `content/site.json`:
- `"galleryView"`: `"shelf"` — подборки лежат книгами на полках (полка = `group`), `"cards"` — карточками с обложками;
- `"homeView"`: `"shelf"` — на главной стеллаж с полками групп галереи («Арты», «Комиксы»), «Игры» и «Ссылки», `"cards"` — плитки разделов и блок «Сейчас интересно».

Книги с `"featured": true` (и игры со статусом `new`) получают закладку-ленточку.

### Комиксы

Комикс — это подборка с `"layout": "book"`: книга, которая листается разворотами (на телефоне — по одной странице).
Листать: клик по правой/левой половине, свайп, стрелки ← →. Кнопка ⤢ или Enter открывает страницу крупно.

- **Без обложки** книга сразу открыта на развороте 1–2, дальше 3–4, 5–6…
- **С обложкой** (в папке комикса есть файл со словом «обложка» или «cover») сначала видна закрытая книга, потом 1–2, 3–4…

Вместо книги можно сделать горизонтальную ленту: `"layout": "strip"`.

### Подборка из постов (ссылок)

`"layout": "links"` — на полке это книга, а внутри карточки, которые ведут на посты (например, в Telegram).
Вместо `images` у такой подборки список `items`:

```json
{
  "id": "travel",
  "title": "Поездки",
  "group": "Арты",
  "layout": "links",
  "items": [
    { "title": "Грузия. Сатаплия", "url": "https://t.me/ame_tanami/32" }
  ]
}
```

Обложки постов: `_originals/gallery/Поездки/Грузия. Сатаплия/cover.png` — папка с названием поста, путь в `image` скрипт впишет сам.

То же самое в разделе «Ссылки» — группа в `links.json` с `id` и `items` (так сделаны «Записки домоседа вне дома» и «Обзоры скетчбуков»), оригиналы обложек: `_originals/links/Записки домоседа вне дома/<Название поста>/cover.png`.

### Видео вместо обложки

Если в папке карточки (игры, ссылки, поста) нет картинки, но есть `.mp4` — оно станет живой обложкой: крутится по кругу без звука. Видео не сжимается, так что лучше короткое и лёгкое (до 3–5 МБ).

### Видеоподборка

Карточка в `links.json` с `"id"` и `"layout": "videos"` открывает страницу с плеерами (как «Анимации»).
Видео кладутся в папку карточки: `_originals/links/Анимации/Hesti.mp4` — скрипт скопирует их и сам заполнит список `videos`.
Названия берутся из имён файлов; их можно поправить в JSON (поле `title`) — при следующих запусках они сохранятся.
`url` карточки становится кнопкой внизу страницы, её текст — `moreLabel`. Видео не сжимаются: лучше до ~20 МБ на файл.

### Стикерпаки (наборы видео)

«Анимированные стикеры» — карточка с `"layout": "packs"`. Каждая подпапка — отдельный пак:

```text
_originals/links/Анимированные стикеры/
  50 оттенков спасибо/   ← видео-превью стикеров (.mp4)
  Новый пак/
```

Скрипт сам добавит пак в список `packs` в `links.json`. Дальше у пака впиши `url` (ссылка addstickers), `moreLabel` (текст кнопки) и, если хочешь, `description`.
На странице каждый пак — заголовок, превью (крутятся сами) и кнопка «Добавить».

### Группа ссылок

Карточка в `links.json` с полями `id` и `items` открывает свою страницу со списком (например, «Обзоры скетчбуков»).
Обложки постов — подпапки: `_originals/links/Обзоры скетчбуков/Первый микро-скетчбук 2025/cover.png`.

## Тексты главной и соцсети

Всё в `content/site.json`: имя, приветствие, аватарка, ссылка на канал, названия и описания разделов, список соцсетей в подвале.

## Картинки

- Формат **WebP** (или JPG), около **1600px** по длинной стороне, качество ~80%.
  Удобно жать в [squoosh.app](https://squoosh.app) прямо в браузере.
- Обложки и превью можно меньше — **800–1000px**.
- Имена файлов — латиницей, без пробелов: `witch-01.webp`, а не `Ведьма 1.webp`.
- Если в JSON уже прописан файл, которого ещё нет, — сайт покажет цветную заглушку ✦. Можно заполнять JSON заранее.

## Частые ошибки в JSON

Если раздел сломался, на его месте появится сообщение с именем файла. Почти всегда это:

- **лишняя запятая** после последнего элемента списка: `["01.webp", "02.webp",]` ← нельзя;
- **пропущенная запятая** между блоками `}` `{`;
- кавычки «ёлочки» или ‘одинарные’ вместо обычных `"`.

Проверить файл можно на [jsonlint.com](https://jsonlint.com).

## Как посмотреть сайт у себя на компьютере

Если просто открыть `index.html` двойным кликом, контент не загрузится — браузер не даёт читать JSON с диска.
Нужен локальный сервер:

- **VS Code:** расширение *Live Server* → правой кнопкой по `index.html` → *Open with Live Server*;
- или в терминале в папке проекта: `npx serve`.

## Публикация на GitHub Pages

1. Залить папку в репозиторий на GitHub.
2. *Settings → Pages → Source: Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Дальше контент можно обновлять прямо на сайте GitHub: *Add file → Upload files* для картинок
и значок карандаша для JSON. Сайт обновится сам через минуту-две.

## Как открыть сайт из Telegram-бота

В [@BotFather](https://t.me/BotFather): `/mybots` → бот → *Bot Settings → Menu Button* → вписать адрес сайта.
Кнопка меню бота будет открывать сайт прямо внутри Telegram.

## Поменять цвета и шрифты

В начале `css/style.css`, блок `:root`: `--paper` (фон), `--accent` (акцент), `--accent-2`,
`--tile-1..3` (плитки на главной), `--font-display` и `--font-body`.
